# 智能体工程化项目实战

> **副标题**：从天工具身智能平台到连锁餐饮场景 · 德国双元制本土化课程包
> **学时**：64 课时（16 次课 × 4 课时）｜ **适用**：高职高专 人工智能技术应用 / 大数据技术 / 智能装备技术
> **基线项目**：[天工 Tiangong-EWA](https://github.com/tianqiongenze/tiangong-ewa)（具身智能工厂作业智能体平台）
> **版本**：v1.0（与天工 v1.2 对齐）｜ 编制：2026-10-26

## 0. 这门课解决什么问题

企业不缺"会调 API 的人"，缺的是**能把智能体做到能上线、能审计、能降级、能被验收**的人。

本课程用一套真实工程基线（天工具身智能平台）做"解剖对象"，让学生经历**完整工程闭环**：

```
需求（EARS/SDD） → 领域建模（不变量） → 安全红线（物理世界）
   → 编排闭环（审批/证据/降级） → 数据与性能（1 亿条/预聚合/缓存）
   → 接口与多品牌（REST/MCP/A2A/VDA5050） → 测试（TDD/E2E/压测）
   → 运维（可观测/值班） → 迁移（连锁餐饮）
```

最后 8 课时，学生把同一套方法论**迁移到连锁餐饮场景**（门店巡检、后厨配送、外卖调度），
证明他们掌握的是"工程能力"而不是"背下来的一个项目"。

## 3. 快速开始（教师）


## 4. 快速开始（学生）

```bash
# 1. 环境（详见 docs/07）
git clone https://github.com/tianqiongenze/tiangong-ewa.git
cd tiangong-ewa && python -m venv .venv
.venv/Scripts/python.exe -m pip install -r impl/services/agent-runtime/requirements.txt

# 2. 跑通基线（第一次课作业）
cd impl && python -m pytest -q          # 120 项通过
python tools/demo_run.py                # 下单→分解→审批→执行→证据

# 3. 起服务，打开看板
python -m granian --interface asgi app.server:app --port 8000
# 浏览器 http://localhost:8000/
```

## 5. 课程与工程基线的对应关系

| 课程模块 | 天工工程锚点 | 学生要能做的事 |
|---|---|---|
| 需求与规范 | `specs/constitution.md`、`specs/001-*/spec.md` | 写出一份 EARS 需求 + 验收标准 |

## 6. 版本与同步

本课程包与天工项目**同源同步**：天工发布新版本时，执行

```bash
python tools/sync_upstream.py --tiangong ../Tiangong-EWA
```

脚本会刷新 `upstream/` 快照（版本、测试数、覆盖率、性能指标、文档索引），
并把变化写进 `docs/13_与天工项目同步机制.md` 的同步记录表。机制说明见 `docs/13`。

当前基线：**天工 v1.2 · 120 项单元/接口 + 13 项 E2E · 覆盖率 93% · 1 亿条数据 / P95 1.53 ms**
