## 2. 三步装好

### 2.1 克隆与建环境

```bash
git clone https://github.com/tianqiongenze/tiangong-ewa.git
cd tiangong-ewa
python -m venv .venv
# Windows
.venv/Scripts/python.exe -m pip install -r impl/services/agent-runtime/requirements.txt
# Linux/macOS
.venv/bin/python -m pip install -r impl/services/agent-runtime/requirements.txt
```

### 2.2 跑测试（第一道验收）

```bash
cd impl
PYTHONPATH="packages/tiangong_core;services/agent-runtime" ../.venv/Scripts/python.exe -m pytest -q
# 期望：120 passed（Linux 用 : 分隔 PYTHONPATH）
```

### 2.3 跑演示与起服务

```bash
python tools/demo_run.py            # 看闭环输出
python -m granian --interface asgi app.server:app --port 8000
# 浏览器打开 http://localhost:8000/
```

## 3. 常见环境问题（90% 都在这里）

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | `ModuleNotFoundError: tiangong_core` | 没设 PYTHONPATH | 按 §2.2 设置（Windows 用 `;`，Linux 用 `:`） |
| 2 | `No module named litestar` | 装到了全局 Python | 用 `.venv/Scripts/python.exe -m pip` 装 |
| 3 | 端口占用 | 上次进程没退 | `netstat -ano \| findstr :8000`，结束 PID |
| 4 | 看板空白 | 用 `file://` 打开 | 用 `http://localhost:8000/` |
| 5 | 看板显示"演示兜底" | 接口不可达 | F12 → Network 看 `/tg-api/v1/robots` |
| 6 | 中文乱码（Windows 终端） | 编码非 UTF-8 | `chcp 65001` |
| 7 | `pytest` 找不到 tests | 不在 `impl/` 目录 | `cd impl` 后执行 |
| 8 | 装依赖报磁盘不足 | 缓存占满 | `pip cache purge`；临时目录指向大磁盘 |
| 9 | `Permission denied` 写库 | 数据目录只读 | 换到用户目录或改权限 |
| 10 | 1 亿条实验太慢/占满盘 | 直接跑全量 | 先用 `--rows 1000000` 做小样本 |

## 5. 大数据实验（L4）的取舍

1 亿条数据需要约 17 分钟生成 + 3 分钟预聚合 + 5 GB 磁盘。
课堂时间不够时，用**分级方案**：

| 方案 | 行数 | 生成时间 | 磁盘 | 是否够教学 |
|---|---|---|---|---|
| 演示级 | 20 万 | 2 s | 10 MB | 够（功能正确） |
| 教学级 | 500 万 | 30 s | 260 MB | 够（能看出差异） |
| 完整级 | 1 亿 | 17 min | 5 GB | 最好（数字震撼） |

**建议**：教师机课前跑好完整级并录屏；学生机用教学级复现同样结论。
关键不是"1 亿"这个数字，而是**让学生看到 173 秒与 0.23 毫秒的对比**。
