# 05 · 费曼学习法与布鲁姆认知模型应用指南

| 项 | 内容 |
|---|---|
| 目的 | 把"看起来学会了"变成"确实学会了"，并让"学会"可测量 |
| 两个工具 | 费曼学习法（检验掌握）· 布鲁姆认知模型（设计梯度） |
| 使用位置 | 每次课第 4 课时（费曼）+ 全课程目标分级（布鲁姆） |

---

## 1. 为什么需要这两个工具

高职学生常见的三种"假会"：

| 假会 | 表现 | 检测方法 |
|---|---|---|
| 抄会 | 代码能跑，改一行就崩 | 让他改一个参数并预测结果 |
| 背会 | 名词说得溜，问"为什么"就卡 | 追问三层"为什么" |
| 看会 | 看老师演示觉得简单，自己写不出来 | 白板重写关键逻辑 |

**费曼**治"背会"与"看会"；**布鲁姆**治"目标含糊、评价拍脑袋"。

---

## 2. 费曼学习法：本课程的四个动作

### 2.1 标准四步（课堂版，15 分钟）

```
① 选一个概念（教师指定，写在黑板上）
② 讲给同伴听（3 分钟，不许看笔记）
③ 卡住的地方记下来（"我讲不清 X"）
④ 回到材料补 X，再讲一遍（2 分钟）
```

### 2.2 讲解质量的三个判据（学生互评用）

| 判据 | 合格表现 | 不合格表现 |
|---|---|---|
| 无术语依赖 | 用生活类比解释 | "就是那个……CQRS 你懂吧" |
| 有因果 | 说"因为…所以…" | 只罗列"是什么" |
| 能举例 | 举一个具体场景 | 全程抽象 |

### 2.3 每次课的费曼题（已写入各教案）

| 次课 | 费曼题（示例） |
|---|---|
| S01 | 这门课和"AI 应用开发"有什么不同？ |
| S02 | 用开车解释大脑/小脑/脊髓 |
| S05 | 为什么不能有"临时开启"开关？ |
| S08 | 什么错误不能重试？ |
| S10 | 为什么加了索引反而慢？ |
| S13 | 为什么先止损再定位？ |
| S16 | 你最大的技术判断失误是什么？ |

### 2.4 教师操作要点

- **抽人而非自愿**：每次抽 2–3 人，覆盖不同水平；
- **计时**：3 分钟讲不完 = 没抓住重点；
- **不打断**：讲完再纠错，打断会让学生不敢讲；
- **记录**：在《费曼记录表》上记"讲清/讲部分/讲不清"，纳入过程性评价（10%）。

### 2.5 费曼的"反向用法"（作业）

作业里设一道"讲给家长听"的题：

> 用你爸妈能听懂的话，解释"为什么系统要说'证据不足，不能算完成'"（150 字）。

批改标准：出现"trace/span/OTel"等术语即扣分。

## 3. 布鲁姆认知模型：目标与评价的刻度

### 3.1 六级与本课程的动词表

| 层级 | 可测量动词 | 本课程典型任务 |
|---|---|---|
| 记忆 | 说出、列出、定义 | 说出五条红线 |
| 理解 | 解释、举例、区分 | 用开车类比三层架构 |
| 应用 | 使用、实现、执行 | 实现一次红线拦截 |
| 分析 | 对比、归因、拆解 | 分析 173 秒的根因 |
| 评价 | 判断、论证、评审 | 评审同学方案是否可上线 |
| 创造 | 设计、迁移、重构 | 设计餐饮版红线与闭环 |

### 3.2 16 次课的层级分布

```
S01–S02  记忆/理解   ████
S03–S07  应用        ██████████
S08–S11  分析        ████████
S12–S13  评价        ████
S14–S16  创造        ████（课后延伸）
```

### 3.3 同一个知识点的"六级提问链"

以"降级阶梯"为例：

| 层级 | 提问 |
|---|---|
| 记忆 | L1–L4 分别是什么？ |
| 理解 | 为什么 L3 是"人接管"而不是"再试一次"？ |
| 应用 | 给定"机器人连续 3 次定位失败"，你选哪级？ |
| 分析 | 这四级里哪一级最容易造成"看起来恢复了其实没恢复"？ |
| 评价 | 你认为本项目把 L4 设为"挂起"合理吗？给出理由。 |
| 创造 | 给餐饮外卖场景设计一套降级阶梯，并说明与工厂版的差异。 |

> 用法：课堂提问按链条推进；考试按层级配分（记忆 20%、理解 25%、应用 30%、分析 15%、评价 10%）。

## 4. 两者如何配合

| 阶段 | 布鲁姆 | 费曼 |
|---|---|---|
| 课初 | 用"记忆/理解"级问题唤醒旧知 | — |
| 课中 | 用"应用/分析"级任务驱动 | — |
| 课末 | 用"评价"级问题收束 | **用费曼检验是否真懂** |
| 课后 | 用"创造"级作业延伸 | 用"讲给家长听"巩固 |

一句话：**布鲁姆管"教到什么深度"，费曼管"到底进没进去"。**

## 5. 评价与记录

### 5.1 费曼记录表（每次课一张）

| 组 | 姓名 | 题目 | 无术语依赖 | 有因果 | 能举例 | 判定 |
|---|---|---|---|---|---|---|
| 1 | 张三 | S10-为什么索引慢 | ✓ | ✓ | ✗ | 讲部分 |

判定规则：3 项全 ✓ = 讲清（3 分）；2 项 = 讲部分（2 分）；≤1 项 = 讲不清（1 分）。

### 5.2 布鲁姆覆盖检查（备课自查）

每次课教案必须回答：

- [ ] 本次课最高到哪一级？
- [ ] 有没有"分析"及以上的任务？（只有记忆/理解 = 不合格的课）
- [ ] 评价方式能否区分"应用"与"创造"？

### 5.3 数据用于改进

学期末统计：

```
每个费曼题目的"讲不清率" → 找出最难讲清的概念 → 下一轮加时间/换类比
```

经验：**"为什么索引不够快"和"为什么审批不能自动化"是最难讲清的两题**，
说明这两处需要更强的类比与更多动手。

## 6. 教师常见误区

| 误区 | 后果 | 纠正 |
|---|---|---|
| 费曼变成"复述课文" | 学生背一遍，没检验作用 | 强制"不许用术语 + 必须举例" |
| 只抽好学生 | 差生永远不暴露问题 | 按学号轮转，覆盖全员 |
| 布鲁姆只写在教案上 | 课堂仍是"讲—听—抄" | 每个知识点至少设计 1 个"分析"级任务 |
| 用"创造"级任务做入门 | 学生挫败 | 创造类任务放在有脚手架之后（S14 起） |
