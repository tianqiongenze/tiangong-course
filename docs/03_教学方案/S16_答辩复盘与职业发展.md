## 2. 重点与难点

- **重点**：讲"为什么这么做"而不是"做了什么"；用证据说话。
- **难点**：学生答辩爱念功能清单。
- **突破**：规定 PPT 结构（问题/方案/证据/不足各 2 页），功能清单不得超过 1 页。

---

## 3. 企业情境（Lernsituation）

> 这是"客户验收会"而不是"课堂汇报"：企业评委只关心三件事——
> 能不能用、出问题怎么办、要花多少钱维护。

## 5. 关键内容

### 5.1 答辩结构（10 页以内）

| 页 | 内容 | 要点 |
|---|---|---|
| 1 | 封面 | 项目名 + 组员 + 一句话定位 |
| 2–3 | 问题 | 谁的什么痛？现在怎么解决？代价多大？ |
| 4–6 | 方案 | 架构图 + 一条关键链路 + **红线在哪一行** |
| 7–8 | 证据 | 运行截图/测试结果/性能数据/用户反馈 |
| 9 | 不足 | 诚实列出 2–3 个未解决问题 |
| 10 | 下一步 | 3 个月计划 |

### 5.2 三个必答质询

1. "如果机器人突然不动了，你的系统会怎样？"（降级）
2. "你怎么证明这一单真的完成了？"（证据）
3. "如果我要改一条规则，要改几个地方？"（可维护性）

### 5.3 AAR 复盘三问

```
① 预期发生什么？实际发生了什么？
② 差异的根本原因是什么？
③ 下次具体改哪一个动作？（要可执行）
```

### 5.4 职业路径

| 方向 | 岗位 | 起薪参考（一线城市，2026） | 需要补什么 |
|---|---|---|---|
| 智能体开发 | AI 应用开发工程师 | 8–15 K | 工程化 + 一个完整项目 |
| 数据/平台 | 数据平台工程师 | 8–14 K | SQL 调优 + 分布式基础 |
| 交付/实施 | 解决方案/FDE | 7–12 K | 沟通 + 现场排障 |
| 升学 | 专升本/本科 | — | 数学 + 英语 |

> 证书：1+X《人工智能应用开发》（中级/高级）；竞赛：职业院校技能大赛"人工智能应用技术"赛项。

---

## 6. 学生任务（Arbeitsauftrag）

**必做**：完成答辩（8 min 讲解 + 质询）。
**必做**：提交个人复盘卡 + 3 个月成长计划。
**选做**：把项目整理成作品集页面（GitHub README + 演示视频）。

---

## 7. 费曼检验（终局）

| # | 问题 | 合格标准 |
|---|---|---|
| 1 | 用一句话说清你的项目解决了谁的什么问题 | 外行能听懂 |
| 2 | 你最大的技术判断失误是什么？ | 能具体到某次决策 |
| 3 | 如果重做一次，你会先做什么？ | 有明确优先级 |

---

## 8. 评价

见 `assessment/答辩评分表.md`：问题理解 20 / 方案合理性 20 / 工程实现 20 / 安全与合规 20 / 表达与答辩 20。

**一票否决**：无法说明红线实现位置，或承认红线可被绕过 → 安全维度 0 分，整体不及格。

---

## 9. 作业（课程结束）

- 提交完整项目包：代码 + 文档 + 演示视频 + 复盘报告；
- 优秀作品推荐参加校级/省级技能竞赛，或作为实习作品集。
