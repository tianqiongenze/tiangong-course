## 2. 重点与难点

- **重点**：协议选型（人用 REST、模型用 MCP、智能体间用 A2A、设备用 VDA 5050）。
- **难点**：学生容易"一个接口打天下"。
- **突破**：给 4 个场景，让学生选协议并说明理由。

## 5. 关键内容

### 5.1 四协议对照

| 协议 | 面向 | 典型用途 | 特点 |
|---|---|---|---|
| REST | 人/前端 | 看板、运维接口 | 简单、通用、易调试 |
| MCP | 大模型 | 让模型调用工具 | 结构化、可发现（tools/list） |
| A2A | 智能体之间 | 跨平台委派任务 | Agent Card + 意图 |
| VDA 5050 | 设备 | 跨品牌 AGV/AMR | MQTT 主题 + 标准报文 |

### 5.2 适配器三条纪律

1. **只翻译协议**，不做业务决策（决策在核心层）；
2. **不改核心**：新增品牌只加适配器 + 注册；
3. **必须可降级**：适配器故障不能拖垮编排主链路。

### 5.3 契约先行

- 先写 proto/OpenAPI/报文样例，再写实现；
- 契约变更要走版本（v1 → v2），不允许"悄悄改字段"。
