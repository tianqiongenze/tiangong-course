## 评分维度（每维 20 分，加权后总分 20 分）

### 1. 问题理解（20 分）

| 分数段 | 判据 | 得分 |
|---|---|---|
| 16–20 | 说清"谁的什么痛"，有量化（频次/耗时/代价） | |
| 11–15 | 说清问题，但缺量化 | |
| 6–10 | 问题模糊（"提升效率"） | |
| 0–5 | 说不清在为谁解决什么 | |

### 2. 方案合理性（20 分）

| 分数段 | 判据 | 得分 |
|---|---|---|
| 16–20 | 架构清晰，选型有取舍论证（为什么不用 X） | |
| 11–15 | 方案合理但缺对比 | |
| 6–10 | 能跑但说不清为什么这么设计 | |
| 0–5 | 堆技术名词 | |

### 3. 工程实现（20 分）

| 分数段 | 判据 | 得分 |
|---|---|---|
| 16–20 | 现场演示顺畅，且能演示异常路径（红线/降级） | |
| 11–15 | 主链路可演示 | |
| 6–10 | 只能放录屏/截图 | |
| 0–5 | 跑不起来 | |

### 4. 安全与合规（20 分，**一票否决**）

| 分数段 | 判据 | 得分 |
|---|---|---|
| 16–20 | 能指出红线代码位置，能演示拦截，数据脱敏合规 | |
| 11–15 | 知道红线，但定位含糊 | |
| 6–10 | 只说"有做"，无法举证 | |
| 0 | 承认红线可被绕过 / 说不清红线在哪 | |

> **否决规则**：本维度 0 分 → 答辩不及格，课程总评不及格。

### 5. 表达与答辩（20 分）

| 分数段 | 判据 | 得分 |
|---|---|---|
| 16–20 | 8 分钟讲完，质询回答有依据，主动说不足 | |
| 11–15 | 讲完但超时，质询基本能答 | |
| 6–10 | 念稿，质询答非所问 | |
| 0–5 | 讲不清 | |

## 质询问题库（评委按需选 3 个）

1. 如果机器人突然不动了，你的系统多久能发现？怎么发现？
2. 你怎么证明这一单真的完成了？
3. 如果我要改一条规则，要改几个地方？
4. 你的系统最可能在哪里崩？崩了怎么办？
5. 这套东西换到另一家门店/工厂，要改多少？
6. 你最大的技术判断失误是什么？
7. 如果预算砍一半，你先砍什么？
