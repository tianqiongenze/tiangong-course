## 2. 达成度计算

```
单个目标达成度 = 该目标考核点平均得分 / 满分
课程总体达成度 = Σ(单目标达成度 × 权重)
```

## 3. 结果判读与改进

| 达成度 | 判读 | 动作 |
|---|---|---|
| ≥ 0.85 | 优秀 | 保持，可提高选做要求 |
| 0.70–0.84 | 良好 | 微调 |
| 0.60–0.69 | 合格 | 找出最低的 2 个目标，改进教法 |
| < 0.60 | 不合格 | 课程组复议，重设考核或补课 |

### 3.1 改进记录模板

```
本轮最低目标：A5（0.58）
原因分析：S10 时间不足，学生只跑了演示级数据，没看到数量级差异
改进措施：课前预生成教学级数据并分发；课堂只做"跑 + 读 + 结论"
责任人 / 完成时间：______ / ______
```
