## 1. 检查表

| # | 检查 | 命令 | 期望 | 结果 |
|---|---|---|---|---|
| 1 | Python 版本 | `python -V` | 3.12 或 3.13 | ☐ |
| 2 | 虚拟环境 | `ls .venv/Scripts/python.exe`（Win） | 文件存在 | ☐ |
| 3 | 依赖完整 | `.venv/Scripts/python.exe -c "import litestar, pytest"` | 无报错 | ☐ |
| 4 | 代码可导入 | `PYTHONPATH="packages/tiangong_core;services/agent-runtime" python -c "import tiangong_core"` | 无报错 | ☐ |
| 5 | 测试通过 | `pytest -q` | 120 passed | ☐ |
| 6 | 演示可跑 | `python tools/demo_run.py` | 输出 DONE | ☐ |
| 7 | 服务可起 | `python -m granian --interface asgi app.server:app --port 8000` | `/healthz` 返回 ok | ☐ |
| 8 | 看板可开 | 浏览器 `http://localhost:8000/` | 显示"数据源：实时 API" | ☐ |

> Windows 的 `PYTHONPATH` 用 `;` 分隔，Linux/macOS 用 `:`。

## 2. 常见失败与处理

| 失败项 | 处理 |
|---|---|
| 3 / 4 失败 | 用 `.venv/Scripts/python.exe -m pip install -r requirements.txt` 重装 |
| 5 失败且报 `ModuleNotFoundError` | 检查 PYTHONPATH 与工作目录（应在 `impl/`） |
| 7 失败且端口占用 | 换端口 `--port 8010` |
| 8 显示"演示兜底" | 服务未起或地址错；F12 看请求 |
| 磁盘不足 | 清理 pip 缓存；大数据实验改用 `--rows 200000` |
