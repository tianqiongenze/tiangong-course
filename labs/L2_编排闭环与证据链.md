## 1. 跑通一次闭环

```bash
BASE=http://localhost:8000
# 1) 下单
curl -s -X POST $BASE/tg-api/v1/work-orders -H 'Content-Type: application/json' -d '{
  "kind":"TRANSPORT","params":{"from":"原料库","to":"装配车间","what":"电池包",
  "weight_kg":35,"x":25,"y":14},"requested_by":"学生"}'
# 2) 审批（换成上一步的 order_id）
curl -s -X POST $BASE/tg-api/v1/work-orders/<ID>/approve -H 'Content-Type: application/json' -d '{"approved_by":"教师"}'
# 3) 执行
curl -s -X POST $BASE/tg-api/v1/work-orders/<ID>/run -H 'Content-Type: application/json' -d '{}'
```

**观察 RunReport 里的字段**：`trace_id`、`tasks[].status`、`tasks[].evidence`、`degrade_level`、`aborted`。
