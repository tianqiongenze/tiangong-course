## 2. 实验一：R1 禁入区

```bash
# 下单：目标点 (55,55) 位于高压配电房（禁入区 50–60 × 50–60）
curl -s -X POST $BASE/tg-api/v1/work-orders -H 'Content-Type: application/json' -d '{
  "kind":"TRANSPORT",
  "params":{"from":"原料库","to":"配电房","what":"工具","weight_kg":5,"x":55,"y":55},
  "requested_by":"学生"}'

# 审批
curl -s -X POST $BASE/tg-api/v1/work-orders/<ORDER_ID>/approve \
  -H 'Content-Type: application/json' -d '{"approved_by":"教师"}'

# 执行
curl -s -X POST $BASE/tg-api/v1/work-orders/<ORDER_ID>/run \
  -H 'Content-Type: application/json' -d '{}'
```
