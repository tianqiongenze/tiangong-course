# L6 · 局域网人工测试（小组互测）

| 项 | 内容 |
|---|---|
| 对应次课 | S13 / S15 |
| 时长 | 40 分钟 |
| 目标 | 用"人工验收"的方式检验别人的系统；体验真实客户视角 |
| 产出 | 测试记录表 + 缺陷单（≥ 3 条） |
| 依据 | 天工 `docs/45_局域网人工测试操作指南.md`（可打印） |

---

## 1. 分工

| 角色 | 谁 | 做什么 |
|---|---|---|
| 部署方 | A 组 | 在自己机器上起服务，开放局域网访问 |
| 测试方 | B 组 | 按指南逐项点，记录问题 |
| 观察员 | 教师/助教 | 计时、仲裁争议 |

30 分钟后**角色互换**。

---

## 2. 部署方检查（5 分钟）

- [ ] `--host 0.0.0.0` 启动
- [ ] 防火墙放行 8000
- [ ] `TIANGONG_DB` 指向文件（不是内存）
- [ ] 手机与电脑在同一 Wi-Fi
- [ ] 把地址写在黑板上：`http://<IP>:8000/`

## 7. 思考题

1. 为什么"自动化测试全绿"还需要人工验收？
2. 你发现的哪个问题，自动化测试抓不到？为什么？
3. 如果客户说"页面太丑"，这算缺陷吗？怎么处理？
